# PraxisQM – Administratorhandbuch

Dieses Dokument beschreibt später die Bedienung des Adminbereichs.

Geplante Inhalte:

- Benutzerkonten verwalten
- Mitarbeiterregister pflegen
- Kategorien verwalten
- Schlagwörter verwalten
- Dokumente archivieren
- Neue Versionen hochladen
- Backups erstellen
- Backups wiederherstellen
- Datenbankmanager nutzen
