# ADR-009 - Einführung eines Design Systems

## Status
Beschlossen

## Entscheidung
PraxisQM erhält ein eigenes Design System als zentrale Grundlage für Design Tokens, Component Library, UI Style Guide und Mockup Collection.

## Begründung
Dadurch werden doppelte Designinformationen vermieden und die Benutzeroberfläche bleibt langfristig konsistent.
