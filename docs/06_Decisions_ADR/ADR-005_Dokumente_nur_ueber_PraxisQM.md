# ADR-005 – Dokumente werden ausschließlich über PraxisQM eingepflegt

## Status

Beschlossen

## Kontext

Direktes Kopieren von Dateien in Ordner würde dazu führen, dass wichtige Metadaten fehlen.

## Entscheidung

Neue Dokumente und neue Versionen müssen über die Upload-Funktion von PraxisQM angelegt werden.

## Begründung

Nur so können Dokumentennummer, Version, Tags, Verantwortlichkeit und Gültigkeit vollständig gepflegt werden.

## Konsequenzen

- Dateien im Dokumentenordner werden nicht automatisch als QM-Dokumente übernommen.
- PraxisQM ist die zentrale Eingabestelle.
