# PQM-SDD-006 – Core Modules

- 006A Dokumentenverwaltung: Verwaltet Dokumente, Metadaten, Versionen, Archivstatus und Dokumentennummern.
- 006B Dokumentensuche: Ermöglicht das schnelle Auffinden von Dokumenten.
- 006C Kategorien & Schlagwörter: Verwaltet Hauptkategorien, Unterkategorien und Schlagwörter.
- 006D Mitarbeiterverwaltung: Pflegt das Mitarbeiterregister für verantwortliche Personen.
- 006E Benutzer- & Rollenverwaltung: Verwaltet Login-Benutzer, Rollen und Rechte.
- 006F Dashboard: Zeigt berechtigten Personen Statuskacheln.
- 006G Backup & Wiederherstellung: Erstellt und stellt Backups wieder her.
- 006H AuditLog: Protokolliert wichtige Aktionen.
- 006I Einstellungen: Verwaltet globale Systemeinstellungen.
- 006J Einrichtungsassistent: Führt durch die erste Einrichtung.
