# PraxisQM – Testplan

Dieses Dokument sammelt später alle Testfälle.

Beispiele:

- Gast kann Dokument suchen
- Gast kann PDF öffnen
- Editor kann Dokument hochladen
- Dokumentennummer wird automatisch erzeugt
- Dokumentennummer kann nicht geändert werden
- Neue Version erhält gleiche Dokumentennummer
- Archiviertes Dokument verschwindet aus Gast-Suche
- Backup-Erinnerung erscheint korrekt
