# ADR-001 – Dokumentennummern sind unveränderlich

## Status

Beschlossen

## Kontext

QM-Dokumente müssen dauerhaft eindeutig referenzierbar bleiben. Dokumentennummern können in Arbeitsanweisungen, Unterweisungen, Protokollen oder Audits verwendet werden.

## Entscheidung

Dokumentennummern werden automatisch durch PraxisQM erzeugt. Sie sind eindeutig, unveränderlich und werden niemals wiederverwendet.

## Begründung

Eine Änderung oder Wiederverwendung einer Dokumentennummer würde die Nachvollziehbarkeit gefährden.

## Konsequenzen

- Neue Dokumente erhalten immer eine neue Nummer.
- Archivierte Nummern werden nicht erneut vergeben.
- Neue Versionen behalten die ursprüngliche Dokumentennummer.
- Auch Admins können Dokumentennummern nicht ändern.
