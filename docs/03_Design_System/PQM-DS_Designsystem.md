# PraxisQM – Designsystem

## Grundstil

PraxisQM verwendet ein ruhiges, modernes und professionelles Design.

## Farben

- Dunkelblau: Primärfarbe für Navigation und Hauptaktionen
- Petrol/Türkis: Akzentfarbe
- Weiß: Haupt-Hintergrund
- Hellgrau: Karten und Flächen
- Grün: gültig / Erfolg
- Orange: läuft bald ab / Warnung
- Rot: abgelaufen / kritische Aktion
- Grau: archiviert / deaktiviert

## Schrift

- Primär: Inter
- Fallback: Roboto oder systemeigene Sans-Serif-Schrift

## Icons

PraxisQM verwendet ausschließlich Lucide Icons.

## Grundregel

Jede Farbe und jedes Icon hat eine klare Bedeutung. Es werden keine gemischten Icon-Stile verwendet.
